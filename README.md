# Dashboard — панель управления

Интерфейс панели управления с графиками. Учебный проект: данные демонстрационные, подключения к серверу нет.

**Демо:** [https://dashboard-pied-rho-t6hwh9hv0j.vercel.app/](ССЫЛКА_НА_ДЕМО)

## Технологии

- React 18
- Recharts (графики)
- Framer Motion (анимации)
- Lucide React (иконки)
- Tailwind CSS
- Vite

## Запуск локально

```bash
git clone https://github.com/AlexFloch/dashboard.git
cd dashboard
npm install
npm run dev
```

Сайт откроется по адресу, который покажет терминал (обычно `http://localhost:5173`).

## Что я отрабатывал

Визуализацию данных в Recharts, компонентную структуру на React, анимации на Framer Motion, работу с Tailwind CSS.
